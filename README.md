# 旅程共編

一個可以裝到手機主畫面的行程 App（PWA）。資料存在一份 Google 試算表，App 和試算表雙向同步。習慣用表格的同伴可以直接編輯試算表，其他人用 App 編輯。

## 功能

- **地圖總覽**（第一頁）：每天的地點用不同顏色標記並連成路線，上方可切換「全部／D1／D2…」，一眼看出每天集中在哪一區
- **每日行程**：拖曳 ⋮⋮ 調整順序、一鍵「依抵達時間排序」、可以幫每天取主題、有「待排」區放還沒決定的地點
- **營業時間**：用 Google 搜尋地點時自動帶入營業時間；預計抵達時間碰到公休或還沒開門會顯示警告
- **訂位**：記錄狀態、時間、人數、編號、電話或訂位連結、費用；「訂位」頁統計已訂、未訂、候補
- **共編**：所有人讀寫同一份試算表，App 每 30 秒自動同步；斷線時先存在手機，恢復連線後自動上傳

## 設定步驟（約 15 分鐘，只要做一次）

### 1. 建立 Google 試算表後端

1. 開一份新的 Google 試算表，命名例如「東京行程」
2. 選單 **擴充功能 → Apps Script**
3. 刪掉預設內容，貼上 `apps-script/Code.gs` 的全部內容，按儲存
4. 上方函式選單選 `setup` → 按 **執行** → 依提示授權（出現「Google 尚未驗證這個應用程式」時，點「進階 → 前往（不安全）」，這是你自己的程式碼）
5. 回到試算表，會看到 `行程設定`、`每日`、`地點` 三個工作表
6. Apps Script 右上 **部署 → 新增部署作業** → 類型選 **網頁應用程式**
   - 執行身分：**我**
   - 誰可以存取：**所有人**
7. 按部署，複製「網頁應用程式網址」（結尾是 `/exec`）

> 之後如果修改 Code.gs，要到 **部署 → 管理部署作業 → 編輯 → 版本選「新版本」** 才會生效，網址不變。

### 2. 申請 Google 地圖金鑰

1. 到 [Google Cloud Console](https://console.cloud.google.com/) 建立專案，並設定帳單（每月有免費額度，個人旅遊用量通常不會收費）
2. **API 和服務 → 程式庫**，啟用：
   - Maps JavaScript API
   - Places API (New)
3. **API 和服務 → 憑證 → 建立憑證 → API 金鑰**
4. 編輯金鑰：
   - 應用程式限制選 **網站**，加入 `https://你的帳號.github.io/*`
   - API 限制選上面兩個 API

### 3. 上架到 GitHub Pages

1. 在 GitHub 建立新的 repository，例如 `trip-planner`（設為 Public）
2. **Add file → Upload files**，把這個資料夾裡的所有檔案拖進去（保持 `icons/`、`apps-script/` 資料夾結構），Commit
3. repository 的 **Settings → Pages**，Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾 `/ (root)`，儲存
4. 約 1 分鐘後網址會是 `https://你的帳號.github.io/trip-planner/`

### 4. 連線並邀請同伴

1. 用手機打開上面的網址 → 「設定」頁
2. 填入 Apps Script 網址、地圖金鑰、你的名字、旅程名稱、開始日期與天數 → 儲存設定
3. 按 **複製邀請連結** 傳給同伴；他們點開就自動帶入連線設定，只要在「設定」填自己的名字
4. 習慣用表格的同伴：直接把 Google 試算表**共用**給他（右上角「共用」→ 編輯者）

> 想先玩看看：不填任何設定，在「設定」頁按「載入範例資料」，就能在手機上先試用（資料只存在這支手機）。

### 5. 加到手機主畫面

- **iPhone**：用 Safari 打開 → 分享 → **加入主畫面**
- **Android**：用 Chrome 打開 → 右上選單 → **安裝應用程式**／**加到主畫面**

## 同伴在試算表編輯的規則

`地點` 工作表的每一列是一個地點，最少只要填：

| 欄位 | 說明 |
|---|---|
| 天 | 第幾天，填數字 1、2、3…；留空或 0 會放到「待排」 |
| 名稱 | 地點名稱 |
| 地址 | 建議填，App 會自動依地址查座標；只填名稱也會嘗試查詢 |
| 行程關鍵字 | 這次去做什麼，例如地點是「山下埠頭」、關鍵字填「花火大會」；首頁地圖標記顯示前四個字，沒填就顯示名稱 |

其他欄位：

- **ID、更新者、更新時間**：系統自動填，不要手動改
- **順序**：同一天內的排列順序，填數字
- **時間**：預計抵達，格式 `14:30`
- **營業時間**：每行一天，例如 `星期一: 休息`、`星期二: 11:30 – 14:30, 17:00 – 21:00`；只寫一行 `10:00 – 20:00` 代表每天相同
- **訂位狀態**：`未訂`、`已訂`、`候補`、`不需訂位`（填這四種其中一個才會出現在「訂位」頁）
- **緯度／經度**：自動查詢。顯示「查無」代表找不到，請修正地址後把「查無」刪掉，App 下次同步會重新查
- 欄位順序可以調整，也可以自己加欄位（例如「交通方式」），App 不會覆蓋你加的欄位

想要 Excel 檔：試算表選單 **檔案 → 下載 → Microsoft Excel (.xlsx)**。

## 注意事項

- **Excel 桌面版無法即時同步**：同伴要用 Excel 的話，請改用瀏覽器開 Google 試算表（介面和 Excel 很像），或手機裝「Google 試算表」App
- **安全性**：拿到邀請連結或 Apps Script 網址的人都能編輯行程，請只分享給同行的人
- **同時編輯同一個地點**：以最後儲存的人為準；不同地點互不影響
- **更新 App**：重新上傳檔案到 GitHub 後，手機上關掉 App 再打開即可（需要的話把 `sw.js` 第一行的 `v1` 改成 `v2`）

## 檔案結構

```
index.html        畫面
style.css         樣式（支援深色模式）
app.js            主程式
config.js         預設連線設定（可留空，改在 App 內設定）
manifest.json     安裝到主畫面的設定
sw.js             離線快取
icons/            App 圖示
apps-script/Code.gs   貼到 Google Apps Script 的後端程式
```
